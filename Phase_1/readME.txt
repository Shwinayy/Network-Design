# Network Design Project – Phase 1 (UDP + RDT 1.0)

## Overview
This repository contains my Phase 1 implementation of the Network Design Project using UDP sockets in Python. Phase 1(a) demonstrates basic UDP client/server communication where a client sends a message (for example, "HELLO") to a server and the server echoes it back. Phase 1(b) transfers a file over UDP using a simple RDT 1.0 style approach. The file is packetized into fixed size chunks (1024 bytes), sent one packet at a time, and reassembled by the receiver to recreate the original file.

## Quick Start (Run Locally)

### Phase 1(a) UDP Echo Demo
2 seperate terminals

Start server:
python3 1a-server.py

Run client:
python3 1a-client.py

Expected behavior: server echoes message back to client.

### Phase 1(b) UDP File Transfer Demo
Note: the input file must already exist (rainbow image0
2 seperate terminals

Start receiver:
python3 1b-filereceiver.py


Run sender:
python3 1b-filesender.py

Expected behavior: the receiver reconstructs the file and writes it to disk. The output file matches the original file byte-for-byte.

## Known Issues / Limitations
This phase assumes a reliable channel (RDT 1.0). There is no handling for packet loss, corruption recovery, retransmissions, timeouts, or windowing. These features will be added in later phases.
