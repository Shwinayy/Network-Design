PHASE 5 DEMO SCRIPT

SETUP
Download common.py and packet.py into the same folder as TCP_Sender.py and TCP_Rciever.py

Open TWO terminals

Terminal 1 (Receiver):
cd C:\NetworkDesign\Phase5

Terminal 2 (Sender):
cd C:\NetworkDesign\Phase5

INTRO (READ THIS)

“This is our Phase 5 implementation of the TCP over UDP.
We implemented TCP transfer, Flow-control-limited transfer, slow start behavior, and RENO fast retransmission. Time-out congestion control.
We also support all five required scenarios including loss and congestion.”

Note: You can turn on --debug on both sender and receiver to see ACKs and states 

Normal TCP Transfer 1 (NO LOSS / NO ERROR)

Terminal 1 (Receiver):
python src/receiver.py --out test.txt 

Terminal 2 (Sender):
python src/sender.py --in sample_input.bin


Flow-control-limited Transfer (Small Reciever Window)

Terminal 1 (Receiver):
python src/receiver.py --out test.txt --rwnd 3 --debug

Terminal 2 (Sender):
python src/sender.py --in sample_input.bin --debug


Slow Start Behavior:

Terminal 1 (Receiver):
python src/receiver.py --out test.txt --loss 0.0 --debug

Terminal 2 (Sender):
python src/sender.py --in sample_input.bin --debug


RENO Fast Retransmit

Terminal 1 (Receiver):
python src/receiver.py --out test.txt --loss 0.4 --debug

Terminal 2 (Sender):
python src/sender.py --in sample_input.bin --debug


Timeout Recovery

Terminal 1 (Receiver):
python src/receiver.py --out test.txt --loss 0.6 --debug

Terminal 2 (Sender):
python src/sender.py --in sample_input.bin --debug
